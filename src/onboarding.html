◈TubeGate YouTube 与 X 内容过滤

把噪声留在视线之外。

检查 YouTube 推荐和 X 帖子的可见文字；命中规则才隐藏，API 异常时放行。

01 / 连接

需要 TypeSafe API Key

API Key 保存在 Chrome 本地。视频标题、频道名或帖子作者、正文会直接发送至 TypeSafe。密钥不会写入网站页面。

前往 TypeSafe 官网获取 API Key ↗

02 / 选择规则

确认默认过滤规则

默认规则采用 85%–90% 的隐藏阈值。所有默认规则都可以关闭；你也可以在设置中心自定义政治、游戏、娱乐等过滤内容。

03 / 准备好了

防护已就绪

打开 YouTube 推荐，或 X 首页、搜索结果和帖子回复即可过滤。不会分析图片、音频或视频画面。

过滤已开启

任何 API 错误、超时或达到每日配额时，内容都会保持显示。
