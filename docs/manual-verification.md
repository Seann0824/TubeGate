# YouTube 视频过滤：手动验收

状态：待用户验证。下表列的是预期结果，不是已经实测通过的结论。不使用 UI 单元测试。

准备：加载 `dist/`，配置 TypeSafe API Key。先关掉全部内置规则，添加临时规则“仅隐藏标题包含 Minecraft 的视频；其他内容放行”，阈值 80%，到 YouTube 搜索 Minecraft。真实 API 调用会产生账户用量。验收后删除临时规则并恢复需要的默认规则。

| 具体改动 | 手动操作 | 预期结果 |
| --- | --- | --- |
| 0.2 架构升级与配置兼容 | 在旧版保存自定义规则、阈值和 Key，再用同一目录重新加载 0.2 并刷新 YouTube | API Key、原规则和开关仍在；无需重新配置；旧缓存不复用，内容重新分类 |
| 适配器范围 | 在首页、搜索和播放页侧栏检查，再进入频道页、订阅页和独立 Shorts 页面 | 支持范围与旧版一致；不支持的页面不出现过滤控件 |
| 名称与请求预览 | 打开弹窗、引导与设置，查看请求预览 | 名称显示 TubeGate；预览使用 source/type/title/author/text 结构，不包含 ID 或 Key |
| 网站样式拆分 | 在 YouTube 切换深色与浅色主题，并检查隐藏占位符和恢复按钮 | 字体与按钮可读，样式仍生效，布局没有因 CSS 拆分改变 |
| 自定义入口 | 从扩展弹窗点“自定义我不想看的内容” | 打开设置页并定位到“你不想看什么？”区域 |
| 主题示例草稿 | 点“政治 / 时政”，查看名称、隐藏条件、保留条件与阈值，再点取消 | 字段填入可编辑示例；取消后规则列表没有新增项，也不自动屏蔽政治内容 |
| 保存自定义主题 | 再次打开示例，改成自己的范围并保存，然后重新打开设置 | 新规则启用，名称、条件、阈值与修改一致；可独立关闭或删除 |
| 自定义实际效果 | 关闭内置规则，只启用政治规则；分别查看时政视频和排除条件中的课程视频 | 根据该规则进行分类；命中显示自定义名称，排除内容预期保留。实际准确率需观察真实分类结果 |
| 自由填写与其他示例 | 点击“自定义内容”，以及游戏、娱乐示例 | 自定义入口为空白草稿；各示例填入对应主题，不覆盖已有规则 |
| 视频卡片过滤 | 在搜索结果等待分类完成，再检查首页和播放页侧栏 | 命中卡片内容被占位符替换，显示规则和概率；非命中卡片保留 |
| Shorts 推荐卡片 | 在首页或搜索结果找到带有匹配标题的 Shorts 卡片 | 卡片可以被过滤；进入独立 Shorts 播放页后不处理播放器 |
| 恢复原视频 | 点击已隐藏卡片的“恢复显示”，继续滚动 | 原缩略图、标题和菜单恢复；同一页面内不会立即再次自动隐藏 |
| 手动重新检查 | 对已恢复卡片点击“重新检查” | 再次请求判断，可按当前规则重新隐藏 |
| 视频范围隔离 | 打开一个匹配规则的视频，并查看评论、订阅页、历史记录和频道页 | 当前播放器与评论不隐藏；订阅、历史和频道页不注入过滤控件 |
| 无限滚动 | 在首页或搜索页连续向下滚动 | 新出现的视频开始检查；已检查内容不持续增加请求数 |
| 无刷新跳转与旧结果保护 | 检查过程中点另一个视频、搜索不同关键词，再前进/后退 | 页面状态重新计算，旧请求结果不应隐藏新页面的不同视频 |
| 卡片复用与加载 | 快速滚动后返回顶部、切换排序或搜索筛选 | 不出现旧标题对应的占位符覆盖新视频；恢复按钮仍可用 |
| 全局暂停 | 在扩展弹窗关闭保护，等待约 3 秒 | 所有已隐藏卡片恢复；在途旧结果不重新隐藏它们 |
| 修改规则与阈值 | 修改隐藏条件，或把阈值调高到超过某条已缓存概率 | 保存内容不丢失；当前页面重新判断；仅改阈值不增加该内容的 API 请求 |
| 没有 Key | 删除 Key 或用未配置的扩展访问 YouTube | 所有视频正常显示，状态提示配置 Key |
| API 异常与预隐藏 | 开启“判断完成前隐藏新视频”，在开发者工具阻止 TypeSafe 请求，再检查新卡片 | 请求失败或超时后卡片恢复，并显示可重试状态，不永久留白 |
| 配额保护 | 把每日限额设为当前请求数或更低，检查未缓存视频 | 不再发起视频分类请求；新视频放行，已有有效缓存仍可使用 |
| 并发保护 | 并发改为 1，快速滚动加载新视频 | 后台同时最多一个视频分类请求，不因重复扫描大量叠加 |
| 详细占位与检查按钮 | 关闭详细占位符、置信度和检查按钮 | 紧凑占位符仍能恢复视频；概率和卡片检查入口按设置隐藏 |
| 深浅色与布局 | 切换 YouTube 明暗主题、缩小窗口，分别查看网格和侧栏 | 占位符可读、恢复按钮可点击，不覆盖邻近卡片 |
| 缓存与安全导出 | 再次查看相同卡片；导出配置 JSON | 相同内容可命中缓存；导出文件不包含 API Key |

若出现漏处理，记录所在页面（首页/搜索/播放页侧栏）、普通视频或 Shorts，以及该卡片的外层元素名称。不要把 API Key 放进截图、日志或反馈。


## TypeScript 迁移、界面与自定义滚动条（待用户验收）

具体改动：源码、构建和非 UI 测试改为 TypeScript；浏览器加载打包产物。设置、弹窗和安装引导采用暖白、灰绿、衬线标题；过滤规则前置。滚动条使用独立 DOM 控件，隐藏原生轨道；规则弹窗支持 Escape、焦点回到入口和背景滚动锁定。

| 操作 | 预期结果 |
| --- | --- |
| `npm ci` 后运行 `npm run package`，Chrome 重新加载 `dist/` 并刷新 YouTube | 扩展入口无丢失；原密钥、自定义规则、阈值和开关保留 |
| 打开设置页、弹窗与安装引导页 | 暖白底、深灰文字、灰绿按钮统一；主要入口为添加规则，无暗色残留 |
| 滚动设置页，再拖拽右侧滑块、点击轨道；聚焦滑块后按方向键/PageUp/PageDown/Home/End | 只有细窄灰绿自绘滑块，无系统灰色滚动槽；位置同步，可到达顶部和底部 |
| 窗口缩窄到约 390px，使用触控板/触屏浏览 | 页面可滚动，导航可横向滑动，内容不被滚动条遮挡 |
| 打开“添加规则”，在较矮窗口中滚动弹窗 | 弹窗出现独立自绘滑块，背景页面不跟着滚动 |
| 在隐藏/保留条件中输入多行内容并调整文本框高度 | 文本框只在溢出时出现自绘滑块，大小和位置随内容、文本框高度更新 |
| 打开高级设置，滚动请求预览区域 | 请求预览有自己的自绘滑块，页面主滑块独立工作 |
| 新增规则、启停规则、开关弹窗、调整窗口高度 | 主滑块随内容长度更新；无溢出时消失；关闭弹窗后恢复页面滚动 |
| 选择“政治 / 时政”示例，编辑保留条件，将阈值从 50% 拉到 99% 并保存 | 示例先为草稿；保存后加入规则；右侧代表更少误伤；刷新后保留（真实扩展中） |
| 用 Tab 浏览规则编辑器，按 Escape 退出 | 焦点留在编辑器内，关闭后回到入口；正文位置保留 |

设计预览用于用户查看与操作，不代表真实 Chrome 扩展、TypeSafe 或 YouTube 已通过验收。以上 UI 项目没有自动单元测试，当前均待用户实际验证。
